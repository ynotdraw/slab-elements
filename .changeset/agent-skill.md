The package includes an agent skill, `skills/slab`, that teaches coding agents such as Claude Code, Cursor and Codex to use Slab: which component fits, its native events and methods, forms and validity, styling with `::part()` and `:state()`, and what not to do for accessibility. A reference page for each component, built from `custom-elements.json`, comes with it. Add it with `npx skills add ynotdraw/slab-elements --skill slab`, or copy it from `node_modules/slab-elements/skills/slab`. [LLMs and agents](https://slab-elements.dev/llms/) has more.
