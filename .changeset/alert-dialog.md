Adds Alert Dialog, `slab-alert-dialog`: a modal Dialog with `role="alertdialog"` for a question that needs an answer, such as confirming a delete. It has a built-in Cancel button that focus starts on, a `description` that's read with the label, and no light dismiss. Change the Cancel button's text with `cancel-label`, or with `alertDialogCancel` in `registerStrings()`.
